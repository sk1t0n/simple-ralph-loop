# simple-ralph-loop

Простой Ralph Loop для задач не связанных с программированием.

## Требования

- [Opencode](https://opencode.ai/)

## Использование

Пример запуска скрипта в Linux:

```bash
sudo chmod +x ralph.sh # сделать скрипт исполняемым
./ralph.sh tasks.txt   # запустить скрипт
```

Пример `tasks.txt`:

```txt
Напиши черновик делового письма.
Исправь ошибки и улучши стиль следующего текста: <TEXT>.
Сделай краткую выжимку (самари) для следующей статьи: <URL>.
```

Прогресс выполнения задач можно посмотреть в файле `progress.txt`.
